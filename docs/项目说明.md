# 项目说明 — jev-cli

> 一页版。完整的安装、命令、校准、坑和限制在仓库根目录的 [`README.md`](../README.md)。

## 一句话

把一段聊天记录粘进终端，它给出**结构化判断**（对方真实意图、危险等级、对方要什么、下一步该做什么）
和**3 条按优先级排好序的候选回复**，你自己决定发不发、发哪条。

只读你贴进来的对话：不接任何聊天软件、不读账号、不自动发送、只把候选复制到剪贴板。

```
对方 你今天是不是又忘了我跟你说过什么？
我   记得，你先别提示我，让我自己说。
对方 那你说。
我   等一下，我想说完整一点。
对方 你最好是。

▍结构化判断  关系：情侣  耗时 0.8s
  真实意图   确认你是否在乎
  危险等级   █████░░░░░  4.0/9  阴阳怪气/试探
  对方需要   被重视
  最佳动作   先查聊天记录
  提示       先别给实质内容（别硬答） · 紧张未解除 · 话里有话

▍候选回复 耗时 1.1s + 排序 0.8s
  ✔ 1. 我这就去翻一下咱们的聊天记录，确认好了马上跟你说，不想瞎蒙你。
    2. 你这一句“你最好是”让我有点慌，先别急，我认真回想一下，不糊弄你。
    3. 不用等了，你直接告诉我是什么事吧，我想马上确认，不想让你觉得我不在乎。

  → 建议发第 1 条  最佳动作是先查聊天记录，候选1明确说去核实而非假装记得，最符合要求。
```

## 原理：判断和生成严格分工

```
粘贴的对话（最近 10 条 + 关系描述）
      │
      ▼  ① judge     7 道结构化判断题，一次请求全发
      │              意图 / 危险等级 / 需求 / 动作 / 是否该给实质 / 紧张是否解除 / 有无潜台词
      │
      ▼  ② draft     生成模型按判断结论起草恰好 3 条候选 —— 禁止自己做判断
      │
      ▼  ③ rank      再让 judge 给 3 条排序，选最该发的一条
      ▼
终端展示 → /copy 复制 → 你自己粘贴发送
```

- judge 只答**选择题 / 打分 / 是非**，永远不写正文；writer 只填字。
  判断和生成混在一个模型里，模型会边写边改判断，输出不稳，所以拆开。
- 判断结果有两个用途：展示给人看 + 当约束喂给生成模型。很多时候它给的价值是
  「**别回**」（best_action=say_less / should_reply_now 低），而不是给话术。
- 系统懂得"该去查记录"而不是硬编（`check_history`），因为模型被明确禁止编造记忆和事实。

## 判断层用的是现成的，本项目的资产是"怎么问"

7 道题的英文 instructions/criteria 来自开源项目
[332_lab-jev-chat](https://github.com/Liyucheng1997/332_lab-jev-chat)（MIT）。
那套措辞是踩坑换来的（修掉了"该不该回"和"最佳动作"互相打架、
对方已经收尾却判成"还要行动"两个矛盾），**换成任何模型都要带着这堆 criteria 走，别自己重写**。

默认 judge 用通用模型（DeepSeek 一次调用输出那 7 个字段），
`--judge jev` 可切回原版的 TypeSafe Jev 判断模型（走 OpenRouter）。

## 边界

| 有 | 没有 |
|---|---|
| 结构化判断 + 3 条候选 + 排序 | 自动读屏采集（对话要你自己粘贴） |
| 本地 JSON 记录、历史回看 | 聊天记录库（`check_history` 只是提示你去翻） |
| 校准脚本（命中率 / 误差 / 门禁） | 群聊支持（判据针对一对一） |
| 56 个离线单测 | `--judge jev` 未实测（本机没 OpenRouter key） |


三条门禁全过。偏弱的地方：danger 差一档（偏低 6 / 偏高 5，MAE 0.400）、
模型偏保守（常把"对方要具体东西"判成"先别给实质内容"）、
已收尾的对话偶尔被判成还有事。逐条差异在 `report/calibration.md`。

## 上手三条命令

```bash
cd ~/jev-cli && ./install.sh      # 装到 ~/.local/bin/jev（无第三方依赖）
jev                               # 交互模式：一行一条消息，/go 分析
jev calibrate                     # 拿标注集量一下判断准不准
```

judge 两种后端、命令速查表、交互命令、用自己的对话做标注集、常见问题，
都在 [`README.md`](../README.md) 里。
